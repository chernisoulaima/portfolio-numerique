Résumé du cours

1. Qu'est-ce qu'un algorithme ?

Une suite finie et non ambiguë d'instructions qui transforme des entrées en sorties. On l'écrit en pseudo-code ou en organigramme avant de coder.

2. Les briques de base

  • Variables et affectation : x ← 5
  • Séquence : les instructions s'exécutent dans l'ordre.
  • Condition : Si … Alors … Sinon … FinSi
  • Boucles : Pour i de 1 à n, TantQue condition

3. Complexité

On mesure l'efficacité en comptant les opérations selon la taille n des données : O(n) pour un parcours, O(log n) pour la recherche dichotomique, O(n²) pour les tris simples.

4. Les algorithmes classiques

  • Recherche du maximum : parcourir en gardant le plus grand vu.
  • Recherche séquentielle : tester chaque case. Dichotomique : couper un tableau trié en deux à chaque étape.
  • Tris : à bulles, par sélection, par insertion.

3 algorithmes et animation de tri

1. Recherche du maximum

Idée : on suppose que le premier élément est le plus grand, puis on parcourt le tableau en remplaçant le maximum dès qu'on trouve plus grand.

Pseudo-code

Fonction Maximum(T, n)
    max ← T[0]
    Pour i de 1 à n-1 Faire
        Si T[i] > max Alors
            max ← T[i]
        FinSi
    FinPour
    Retourner max
FinFonction

Python

def maximum(t):
    m = t[0]
    for x in t[1:]:
        if x > m:
            m = x
    return m

Pas à pas avec T = [4, 9, 2, 11, 7] : max=4 → 9 > 4 donc max=9 → 2 non → 11 > 9 donc max=11 → 7 non → résultat 11.

2. Recherche dichotomique

Idée : dans un tableau trié, on compare la valeur cherchée au milieu ; on élimine la moitié inutile à chaque étape.

Pseudo-code

Fonction Dicho(T, n, x)
    debut ← 0 ; fin ← n-1
    TantQue debut ≤ fin Faire
        milieu ← (debut + fin) div 2
        Si T[milieu] = x Alors Retourner milieu
        SinonSi T[milieu] < x Alors debut ← milieu + 1
        Sinon fin ← milieu - 1
        FinSi
    FinTantQue
    Retourner -1
FinFonction

C

int dicho(int t[], int n, int x) {
    int debut = 0, fin = n - 1;
    while (debut <= fin) {
        int milieu = (debut + fin) / 2;
        if (t[milieu] == x) return milieu;
        if (t[milieu] < x) debut = milieu + 1;
        else fin = milieu - 1;
    }
    return -1;
}

Pas à pas : chercher 23 dans [2, 5, 8, 12, 16, 23, 38] → milieu=12 (trop petit) → [16, 23, 38], milieu=23 → trouvé à l'indice 5 en 2 comparaisons.

3. Tri à bulles

Idée : on compare les éléments voisins et on les échange s'ils sont mal placés ; à chaque passage, le plus grand « remonte » à la fin comme une bulle.

Pseudo-code

Procédure TriBulles(T, n)
    Pour i de 0 à n-2 Faire
        Pour j de 0 à n-2-i Faire
            Si T[j] > T[j+1] Alors
                Échanger(T[j], T[j+1])
            FinSi
        FinPour
    FinPour
FinProcédure

Python

def tri_bulles(t):
    n = len(t)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if t[j] > t[j + 1]:
                t[j], t[j + 1] = t[j + 1], t[j]
    return t

Pas à pas avec [5, 1, 4, 2] : passage 1 → [1, 4, 2, 5] ; passage 2 → [1, 2, 4, 5] ; passage 3 → [1, 2, 4, 5].
