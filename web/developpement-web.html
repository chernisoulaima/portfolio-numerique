Résumé du cours

1. HTML — la structure

HTML décrit le contenu avec des balises. Les balises sémantiques donnent du sens : <header>, <nav>, <main>, <section>, <article>, <footer>. Chaque image a un texte alternatif alt.

<header>
  <nav><a href="index.html">Accueil</a></nav>
</header>
<main>
  <section>
    <h1>Mon portfolio</h1>
    <img src="photo.jpg" alt="Portrait de Soulaima">
  </section>
</main>
<footer>© 2026</footer>

2. CSS — la présentation

  • Sélecteurs (p, .classe, #id) et propriétés (color, margin, font-size).
  • Modèle de boîte : contenu, padding, border, margin.
  • Mise en page : display: flex (une dimension) et display: grid (deux dimensions).
  • Responsive : @media (max-width: 860px) { … } adapte la page au téléphone.
  • Variables CSS : --accent: #5b3fd1; permettent le mode sombre.

3. JavaScript — l'interactivité

  • Sélectionner un élément : document.querySelector("#menu").
  • Réagir à un événement : bouton.addEventListener("click", …).
  • Modifier la page (le DOM) : classList.toggle, textContent.
  • Mémoriser un choix : localStorage.setItem("theme", "dark").

4. Publier avec GitHub Pages

git add . → git commit -m "message" → git push, puis Settings → Pages → Branch : main. Le site est en ligne sur https://nom.github.io/portfolio-numerique/.

Extrait du script du mode sombre :

const btn = document.querySelector("#theme-toggle");
btn.addEventListener("click", () => {
  const html = document.documentElement;
  const next = html.dataset.theme === "dark" ? "light" : "dark";
  html.dataset.theme = next;            // le CSS change les variables
  localStorage.setItem("theme", next);  // mémorisé pour la prochaine visite
});
